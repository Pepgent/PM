### 5.1 命令、口径

枚举两个根的现存子目录；`stat -f '%B'`取出生epoch，阈值`1793512104`即05:48:24Z；通过 `date -u -r "$born" '+%Y-%m-%dT%H:%M:%SZ'`转UTC。**不能用`TZ=UTC stat ... '%SB'`并在格式尾硬写Z**：本环境stat仍输出本地墙钟；早期该次输出不作为UTC证据，以下均来自epoch转换。

```sh
for p in /Users/mouriya/Ext/worktrees/* /Users/mouriya/Ext/code/pepgent/.workers/*; do
  if test -d "$p"; then
    born=$(stat -f '%B' "$p")
    if test "$born" -gt 1793512104; then
      printf '%s ' "$p"; date -u -r "$born" '+%Y-%m-%dT%H:%M:%SZ'
      if test -e "$p/.git"; then git -C "$p" status --short --branch; fi
    fi
  fi
done
```

以下 `W/` = `/Users/mouriya/Ext/worktrees/`，`P/` = `/Users/mouriya/Ext/code/pepgent/.workers/`，均是完整路径的无歧义前缀。clean表示该次`git status --short --branch`只有`##`分支行；N/A表示该路径自身无.git（不据此推断其所有后代也没有）。
