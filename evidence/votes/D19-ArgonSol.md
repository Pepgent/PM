# D19：产品原始意图守护席 Argon 选票

## 意图裁决

- **【定】D19 整体不违背用户原始产品边界。** `U1` 要求 soroi 作为 omp 扩展服务完整 Pepgent，`U13` 要求核心 harness 以 omp 为核心且不修改 omp 宿主，`U23` 要求完整定制走通用户所述全部流程并成为 Pepgent 的 agent 核心。D19 保持 Mux 只透传、eval 模块持有在途状态、Lab 调用控制端点，不改变组件归属，也不修改 omp 宿主；它补齐的是已定控制路径的跨组件线上契约。
- **线上 JSON 的具体字段属于技术/串联选择，不冒充用户原话。** 本席只裁定其是否偏离上述 `(U)` 边界；未找到用户对 `method`、`ok`、`record` 等字段名的逐字指定，因此不把这些字段标成用户本意。
- `D19-01`、`D19-02`、`D19-05` 是缺失设计补充。`D19-01`、`D19-05` 审查通过；`D19-02` 同时设计 `ok:false` 失败分支，违反本仓“设计阶段只写主路径、禁止为失败分支设计处理”的直接规则，因此本席不批准该补充。此结论是规则合规判断，不冒充 `(U)` 本意裁决，也不行使意图否决权。
