## 三、D18-03C：为何替换 v1 的 A 票

### 原 A 的问题成立

已读 remote 当前 Komodo 模板 `templates/komodo/soroi/compose.yaml:31-36`：copy-out 依赖 body `service_completed_successfully`；已读 `src/backend/komodo/mod.rs:356-385`：remote abort 逐步骤执行 StopContainer，注释明确停止会打断后续步骤链；同文 `:273-295` 保留无 copy-out 的 broken 终态分支。

因此，对运行中远程 Program 发出 remote abort 是用户中止主路径，不是需要本轮补设计的异常输入。若只删除无 copy-out 的 Ended 分支，同时未给 abort 一个可达终态，作业生命周期不能按 D6-15 完成终态等待与 remove。v1 的“body 结束不论成败依赖条件”也不是当前 compose 模板已有的可直接切换选项。此前对 A 的赞成未充分处理这一主路径，本票明确撤销该赞成。

### C 消除的冲突与保留的边界

1. v2:48 将 Ended 明确定义为执行终态，并把已请求 abort 的调用方与自然完成调用方分开：前者不读取缺失的 transfer；后者在主路径中仍以 Ended 确认 copy-out 已送达。
2. 不新增终态、结果码或调用方自行推测的状态源；已被中止的调用记 call_aborted，沿用 D6-15 的控制语义。
3. 已读 D6-15（PM `D6-store-service.md:43`）：远程 Program 可直接 remote abort/remove；**远程 Agent 不能照搬该路径**，必须先经 Mux 中止轮次、关闭代、等进程退出，再自然 copy-out、写回 transcript 与批次，最后 remove。v2:51 保留此有序停止路径。
4. 当前插件 `packages/omp-soroi/src/subagent/main/mux-writer.ts:347-359` 的代关闭会发送 mux_close_stdin 并等待结束，不是把“关代”直接等同于 remote abort。该静态读取支持两条停止路径的结构区分；它不证明远程运行已通过。
5. 体自身失败、拷入失败的进一步设计本轮不展开，遵守设计阶段只写主路径；GUI failed/exited 仍按 D12:572 的既有 D9 缺口，不私加 B 终态。

C 是**真实的公开契约修订**，不能称为“实现已经满足旧 D4”。通过后需按 v2 明列位置一致改写 D4/eval，不用旧 Ended 定义派活。本票未授权改变 D6-15 的远程 Agent 记录保全。

## 四、D18-05C：完整引文纠正与隔离模型

v2:57 提供的完整用户引文为：

> “你错了，web对接soroi多租户啊，我说的是多租户概念不侵入soroi，想什么啊”

其定位是原提案已经引用的同一 `bf96d256`。v1 仅引用后半句，并据此把 web 也归入每 Lab 独立部署。本席 v1 对 A 的赞成建立在该不完整引文之上；**本轮不再维持该推断**。发起人所述用户纠正前后的助手发言只作为语境，不以“用户未再否定助手”单独创造用户授权。

完整用户句子的两个部分应同时成立：web 对接多租户；多租户概念不侵入 soroi。结合 v2 引用的“每新增实验室，部署全套 soroi 下的东西，包括 km”，C 给出了相容落点：

- Lab/web 是业务成员、组织、授权及路由的拥有方，Better Auth organization 管多个 Lab；
- 每 Lab 各自的 store、Mux、Komodo、remote home、中心会话/worktree 卷形成独立运行域；
- Lab 根据 labId 请求对应实例，不把 Lab 字段塞进 soroi 组件；
- D12-03/04 的首版 Lab 目录和切换继续存在，openRuns 按各实例来源读取，不能再在一个共享 store 中仅靠 experiment_ext.lab_id 假定隔离；
- 新 Lab 的供给动作按用户已允许的部署占位处理，不为此引入前置调查或同步开工锁。

D7-01 的“进程仍是一个”原本是在讲 Lab/Paseo 进程归属，本席 v1 已指出它不足以证明多个 Lab 共享 soroi；v2 不再依赖该错误论证，而是明确区分一个多租户业务门面和多套无租户概念的 soroi 实例。

**证据边界：** 本席本轮读取了 v2 提案及现有 D7/D12 契约，没有重新读取历史 session。因此上述用户原句按发起人 v2 提供、带 entry 定位的完整引文使用；不把其“全部历史无撤回”报告改称为本人取证结果。即便不采用“未再否定助手”这一推论，完整用户句子本身仍足以否定 v1 中“web 也必然每 Lab 独立”的解读，并支持 C 的层次划分。
